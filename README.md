# CryptoViz   
### Interactive Symmetric Encryption Simulator

CryptoViz is a web-based interactive simulator designed to help users understand how symmetric encryption works through visual demonstrations and real-time interactions.

##  Features

-  Simulate symmetric encryption algorithms
-  Visualize encryption and decryption processes
-  Enter custom plaintext and encryption keys
-  Real-time encryption output
-  Educational and beginner-friendly interface
-  Fully browser-based application

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify (Deployment)

##  How It Works

1. Enter a plaintext message.
2. Provide a symmetric encryption key.
3. Select or simulate an encryption process.
4. View the encrypted ciphertext.
5. Decrypt using the same key to recover the original message.

##  Purpose

This project was created to:

* Demonstrate the fundamentals of symmetric cryptography
* Help students and beginners learn encryption concepts visually
* Provide an interactive educational cybersecurity tool
